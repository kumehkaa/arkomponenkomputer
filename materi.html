Materi 01

Apa Itu Sistem Komputer?

Sistem Komputer adalah kumpulan elemen-elemen atau komponen-komponen terintegrasi yang saling terhubung dan bekerja sama untuk menerima masukan (input), mengolah data (process), menyimpan data (storage), serta menghasilkan informasi (output).

Hardware

Perangkat fisik komputer yang tampak secara nyata dan dapat disentuh langsung oleh tangan.

Software

Program dan instruksi digital yang memberikan arahan agar hardware dapat menjalankan fungsinya.

Brainware

Manusia yang mengoperasikan, mengendalikan, dan mengelola seluruh sistem komputer.

Materi 02

Tiga Komponen Utama Sistem Komputer

Ketiga komponen ini harus ada agar sistem komputer dapat bekerja secara sempurna.

A. Hardware

Hardware adalah bagian komputer yang memiliki bentuk fisik nyata sehingga dapat dilihat, dipegang, dan dipindahkan.

Contoh Utama: Keyboard, mouse, monitor, processor, RAM, dan media penyimpanan.

B. Software

Software adalah kumpulan program, aturan, dan instruksi digital yang digunakan untuk menjalankan tugas tertentu pada sistem komputer.

Contoh Utama: Windows, Linux, Microsoft Word, browser internet, dan Canva.

C. Brainware

Brainware adalah manusia yang mengoperasikan, mengendalikan, dan memanfaatkan perangkat komputer secara bijak dan tepat.

Contoh Utama: Siswa, guru, programmer, analis data, dan teknisi jaringan.
Materi 03

Kelompok Perangkat Keras (Hardware)

Hardware dibagi menjadi 4 kelompok utama berdasarkan tugas dan alur kerjanya.

Kelompok A

Input Device (Perangkat Masukan)

Perangkat yang berfungsi untuk memasukkan data, teks, gambar, suara, atau perintah tertentu ke dalam sistem komputer.

Keyboard

Memasukkan huruf, angka, karakter khusus, dan perintah ketikan.

Mouse

Menggerakkan pointer kursor, memilih objek, dan melakukan klik.

Scanner

Membaca fisik dokumen atau foto menjadi file bergambar digital.

Microphone

Memasukkan dan merekam gelombang suara ke komputer.

Kelompok B

Processing Device (Perangkat Pemrosesan)

Perangkat inti yang bertugas mengolah, menghitung, dan memproses data yang diterima dari perangkat masukan.

Processor (CPU)

Otak utama komputer yang menjalankan seluruh instruksi sistem.

Motherboard

Papan sirkuit utama yang menghubungkan seluruh komponen komputer.

RAM

Tempat penyimpanan data sementara saat aplikasi sedang dijalankan.

Kelompok C

Storage Device (Perangkat Penyimpanan)

Perangkat yang digunakan untuk menyimpan dokumen, file multimedia, dan sistem operasi secara permanen maupun sementara.

Hard Disk Drive (HDD)

Media penyimpanan magnetik berkapasitas besar.

Solid State Drive (SSD)

Media penyimpanan modern berbasis cip flash yang sangat cepat.

Flashdisk

Penyimpanan portabel kecil yang praktis dibawa ke mana saja.

Kelompok D

Output Device (Perangkat Keluaran)

Perangkat yang menampilkan, mencetak, atau memancarkan hasil akhir pemrosesan data kepada pengguna.

Monitor

Menampilkan grafis visual, teks, video, dan antarmuka aplikasi.

Printer

Mencetak file tulisan dan gambar dari komputer ke media kertas.

Speaker

Mengeluarkan efek suara, musik, dan audio dari komputer.

Projector

Memancarkan tampilan layar monitor ke dinding atau layar lebar.

Materi 04

Mengenal Perangkat Lunak (Software)

Perangkat lunak adalah sekumpulan program, prosedur, dan dokumentasi yang memerintahkan komputer agar bekerja sesuai tujuan pengguna.

1. Sistem Operasi

Software paling dasar yang bertugas mengelola seluruh sumber daya hardware komputer dan menjadi fondasi utama bagi aplikasi lain.

Contoh: Windows, Linux, macOS, Android, dan iOS.

2. Perangkat Lunak Aplikasi

Program yang dirancang khusus untuk membantu pengguna menyelesaikan tugas tertentu secara mudah.

Contoh: Ms. Word, Ms. Excel, Ms. PowerPoint, Google Chrome, Canva.

3. Perangkat Lunak Pemrograman

Lingkungan khusus yang digunakan programmer untuk membuat, menguji, dan mengembangkan program komputer baru.

Contoh: Scratch, Python, VS Code.

Materi 05

Siapa yang Mengoperasikan Komputer?

Brainware adalah manusia yang berinteraksi langsung dengan sistem komputer. Tanpa peran brainware, hardware dan software tidak akan berguna.

Siswa & Guru (End User)

Menggunakan komputer untuk kegiatan pembelajaran mandiri, tugas sekolah, ujian online, dan presentasi di kelas.

Programmer

Orang yang memiliki keahlian menulis kode perintah untuk menciptakan program atau website baru.

Teknisi Komputer

Spesialis yang bertugas merawat, memeriksa kerusakan, dan memperbaiki perangkat keras maupun sistem komputer.

Materi 06

Bagaimana Komputer Bekerja?

Sistem komputer mengolah informasi melalui alur kerja berurutan.

1

Input

Data atau instruksi dimasukkan pengguna melalui perangkat masukan.

Contoh: Mengetik angka 5 + 5 pada keyboard.
2

Process

Processor (CPU) mengolah data sesuai perintah yang diterima.

Contoh: CPU menghitung hasil penjumlahan 5 + 5 = 10.
3

Storage

Data dapat disimpan di memori atau media penyimpanan (SSD/HDD).

Catatan: Penyimpanan sifatnya opsional sesuai kebutuhan.
4

Output

Hasil akhir pemrosesan ditampilkan kepada pengguna.

Contoh: Layar monitor menampilkan angka 10.

Rangkuman Pembelajaran

  • Sistem Komputer adalah kesatuan terpadu dari hardware, software, dan brainware untuk mengolah data menjadi informasi.
  • Hardware merupakan komponen perangkat keras fisik komputer yang dapat disentuh.
  • Software adalah program digital berisi petunjuk dan instruksi agar komputer dapat beroperasi.
  • Brainware adalah manusia yang menggunakan dan mengoperasikan sistem komputer.
  • Hardware dibagi menjadi 4 kelompok utama: Input Device, Processing Device, Storage Device, dan Output Device.
  • Alur kerja komputer secara umum mengikuti siklus: Input → Process → (Storage) → Output.
